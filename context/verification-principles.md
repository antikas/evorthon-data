# Verification principles

Use an approved, versioned verification case for one declared comparison boundary. Freeze input, reference or enrichment data, expected output, comparison rules, and lineage or checkpoint evidence. Run the candidate against those facts. Deterministic reconciliation reports the earliest evidence-backed divergence or a bounded unknown interval. Routine verification has no live legacy dependency. Advisory diagnosis may propose causes and fixes. Diagnostic advice cannot change the verification case or decide acceptance. A named human accepts the result.
