# AutoBuild adapter

AutoBuild is consumed as the published `autobuild-factory` distribution and owns
controlled execution of approved eligible work.

`contract.md` names every command and option Evorthon uses. Install the
optional distribution through the `delivery` extra when an adopting delivery
runs a campaign. `pyproject.toml` sets the lower bound and
`uv.lock` records resolved versions; `docs/dependency-contracts.md` explains the version policy.
