# AutoBuild adapter

AutoBuild is consumed as the published `autobuild-factory` distribution and owns
controlled execution of approved eligible work.

`contract.md` beside this file names every command and option Evorthon uses. The
distribution is optional: install it through the `delivery` extra when an
adopting delivery runs a campaign. No version is named here; `pyproject.toml`
owns the lower bound and `docs/dependency-contracts.md` records the dated
resolution.
