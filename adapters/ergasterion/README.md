# Ergasterion adapter

Ergasterion is consumed as the published `ergasterion-factory` distribution and
may generate only declared artefacts.

`contract.md` beside this file names every command, declaration key, output file
and schema Evorthon uses. The distribution is optional: install it through the
`delivery` extra when an adopting delivery generates artefacts. No version is
named here; `pyproject.toml` owns the lower bound and
`docs/dependency-contracts.md` records the dated resolution.
